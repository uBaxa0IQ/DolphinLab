# Границы проверенности

Пользователь запросил подготовку без автотестов и платных исследований. Выполняются только технические сборки, миграции и запуск сервисов с ENABLE_MODEL_CALLS=false. Это не проверка поведения модели, всех сценариев pause/recovery или качества AutoML.

38 прежних локальных тестов конкурсного ядра проходили до текущей интеграции. После изменения точек расширения они ещё не запускались; прежний результат не является проверкой Docker-платформы.

До заявления о стабильности необходимы сквозной прогон с явным API-бюджетом, проверки lifecycle/восстановления/executor, независимой оценки и восстановления backup. Многопользовательская авторизация и изоляция враждебных арендаторов не реализованы.

Наличие workflow не подтверждает публикацию GHCR или branch protection: для этого нужен подключённый репозиторий и выполненный workflow. Результаты технического запуска этой итерации фиксируются в отчёте при завершении.
