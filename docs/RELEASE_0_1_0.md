# DolphinLab 0.1.0

Первый выпуск DolphinLab: личное пространство для автономных исследований табличных ML-задач.

## Входит в выпуск

- Проекты, загрузка входных данных, настройки ресурсов и история запусков.
- Чат с project manager и доставка поручений техлиду.
- Исследовательские команды с ML-инженером, data-инженером и независимым evaluator.
- Сессии LangGraph, PostgreSQL checkpoints, память и квитанции инструментов.
- Отдельный Python executor, ограничения времени и памяти, сохранение исходников и логов.
- Пауза, продолжение, финализация, остановка и восстановление исследований.
- Проверка кандидатов перед публикацией результата и скачивание артефактов.
- Зашифрованное хранение ключа модели, учёт API-расходов и ограничения бюджета.
- React/TypeScript-интерфейс, Docker Compose, миграции и публикация контейнеров в GHCR.

## Запуск

Порядок настройки находится в [README](../README.md), эксплуатация и резервное копирование — в [DEPLOYMENT](DEPLOYMENT.md).
Вызовы модели по умолчанию отключены. Подключение модели и разрешение платных запросов настраиваются отдельно.

## Границы версии

- Одно доверенное пространство; встроенной многопользовательской авторизации нет.
- Один worker исполняет одно исследование одновременно, с параллельной работой внутри запуска.
- Вычисления ориентированы на CPU и предустановленный набор библиотек для табличного ML.
- Основной публикуемый результат — проверенный файл предсказаний `submission.csv`.
- Универсальные аналитические отчёты, агентная сборка страниц, RAG и межитерационная память относятся к следующему этапу развития.

Проверки сборки и контейнеров не подтверждают качество исследований на произвольных данных. Проверка ML-результата выполняется отдельно в конкретном запуске.
