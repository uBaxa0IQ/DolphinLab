# sonder.

Исследовательское пространство с динамическими командами AI-агентов: задачи и данные, чат с PM, эксперименты и независимая проверка результатов.

**React / TypeScript · FastAPI · LangGraph · PostgreSQL · Docker Compose.**

## Запуск

```bash
python scripts/bootstrap_platform.py
docker compose --env-file .env.docker.local up --build -d
```

Открыть **http://localhost:8080**. Нужен Docker Compose. Демопроекты работают без модели. По умолчанию `ENABLE_MODEL_CALLS=false`, API-бюджет не расходуется.

Для реального исследования в профиле сохранить Base URL, модель и API-ключ, создать проект и загрузить задачу/данные. Затем установить `ENABLE_MODEL_CALLS=true` в `.env.docker.local` и пересоздать сервисы:

```bash
docker compose --env-file .env.docker.local up -d --no-deps --force-recreate api worker
```

После включения обрабатываются ожидающие сообщения PM. Исследование запускается явно кнопкой в проекте. Перед включением проверить pending-сообщения и бюджет. Платный сквозной прогон новой платформы ещё не проводился.

## Возможности

- Постоянные проекты, файлы, история PM, поручения и настройки стратегии/ресурсов.
- PM общается с техлидом. Техлид создаёт команды с тимлидом, ML/Data-инженерами и evaluator; состав и направления меняются во время работы.
- Цикл агента в LangGraph, checkpoints и фактическое состояние в PostgreSQL.
- Агенты выбирают методы и пишут весь ML-код; встроенного ML-пайплайна нет.
- Пауза, продолжение, финализация, остановка и восстановление.
- История запусков, события, расходы, исходники, логи и проверенные артефакты.

## Исполнение

`web → api → PostgreSQL` — интерфейс и состояние. `worker → model API` — агенты. `worker → executor` — исполнение кода во внутренней сети. Executor не получает DB/model credentials или Docker socket, запускает код под отдельным UID и ограничен по CPU/RAM/PID. Файлы запусков отделены от загруженных исходных данных.

Это одно доверенное рабочее пространство. Многопользовательская авторизация и защита от враждебных арендаторов не реализованы. По умолчанию HTTP доступен только на loopback; размещение через домен требует HTTPS и внешней аутентификации reverse proxy.
