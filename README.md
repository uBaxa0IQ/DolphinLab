# DolphinLab

Пространство для автономных ML-исследований с динамическими командами AI-агентов.
Загрузите задачу и данные, задайте ресурсы и следите за исследованием через дашборд и чат с project manager.

**React · TypeScript · FastAPI · LangGraph · PostgreSQL · Docker**

## Возможности

- Проекты с описанием задачи, входными файлами и историей исследований.
- Техлид формирует команды и меняет направления работы; тимлиды координируют ML-инженеров, data-инженеров и evaluator.
- Агенты выбирают методы и пишут код экспериментов, опираясь на доступные библиотеки и ресурсы.
- Чат с PM для вопросов о прогрессе и дополнительных поручений техлиду.
- Независимая проверка кандидатов перед публикацией результата.
- Пауза, продолжение, финализация и остановка исследования.
- История событий, расходы API, исходники экспериментов и скачивание артефактов.

## Быстрый старт

Требуются Docker с Compose v2 и Python 3.12+ для создания локальных настроек.

```bash
python scripts/bootstrap_platform.py
docker compose --env-file .env.docker.local up --build -d
```

Откройте [localhost:8080](http://localhost:8080).
В интерфейсе есть демонстрационные проекты для знакомства с пространством.

### Подключение модели

1. В настройках пространства укажите OpenAI-совместимый Base URL, название модели и API-ключ.
2. Создайте проект, опишите задачу и загрузите данные. Описание можно дополнить файлом `task.md`.
3. Настройте длительность, команды, параллельность, CPU и память проекта.
4. Установите `ENABLE_MODEL_CALLS=true` в `.env.docker.local` и примените настройку:

```bash
docker compose --env-file .env.docker.local up -d --no-deps --force-recreate api worker
```

5. Запустите исследование из проекта. PM отвечает на сообщения и передаёт поручения техлиду.

По умолчанию вызовы модели отключены. API-ключ сохраняется на сервере в зашифрованном виде.
Для денежного бюджета укажите тариф и ёмкости запросов в настройках подключения.

## Как устроено исследование

Техлид управляет портфелем гипотез и оставшимся временем. Команды получают отдельные направления, обмениваются находками через техлида и сохраняют факты исследования. Тимлид распределяет работу внутри команды, а evaluator независимо проверяет полученный результат.

Сессии агентов исполняются через LangGraph. PostgreSQL хранит состояние, сообщения, квитанции инструментов и checkpoints. Отдельный executor запускает написанный агентами Python-код с ограничениями ресурсов. У каждого запуска собственные входы, настройки и артефакты.

## Структура

```text
backend/
  src/dolphinlab/
    api/              HTTP-маршруты, схемы и представления
    application/      Сервисы проектов, файлов, сообщений и запусков
    agents/           LangGraph, PM и исполнение исследовательских сессий
    research/         Координатор, команды, память и проверка кандидатов
    domain/           Политика исследования
    infrastructure/   PostgreSQL, LLM, executor, шифрование и расходы
    common/           Общие утилиты
  migrations/         Миграции Alembic
frontend/
  src/
    app/              Сборка интерфейса
    features/         Проекты, исследования, чат и настройки
    components/       Общие компоненты
    lib/              API-клиент и форматирование
    data/             Демонстрационные проекты
executor/
  src/dolphinlab_executor/  Сервис выполнения и supervisor процессов
docs/                 Архитектура, эксплуатация и публикация
scripts/              Настройка окружения и проверка секретов
```
