# Changelog

## 0.1.0 — в разработке

- Docker Compose: PostgreSQL, миграции, FastAPI, worker, изолированный executor и React/nginx.
- Проекты, неизменяемые входы запуска, история PM, стратегия и ресурсные ограничения.
- LangGraph с PostgreSQL checkpoints, динамические команды и независимая проверка результатов.
- Пауза, продолжение, финализация, остановка, история запусков и артефакты.
- Настраиваемый тариф, учёт расхода и резервирование запросов для денежного лимита.
- CI сборки, правила веток и публикация образов в GHCR по релизному тегу.

Платный сквозной прогон новой платформы ещё не проведён. Версия не является подтверждением качества AutoML.
