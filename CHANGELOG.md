# Changelog

## 0.1.0

- Пространство проектов с загрузкой данных, настройками исследования и чатом PM.
- Динамические команды AI-агентов и сессии LangGraph с PostgreSQL checkpoints.
- Раздельные сервисы HTTP API, worker и Python executor.
- Пауза, продолжение, финализация, остановка и восстановление исследований.
- Независимая проверка кандидатов, история запусков и скачивание артефактов.
- Настройки подключения модели, шифрование API-ключа и учёт расходов.
- React/TypeScript frontend с функциональной декомпозицией.
- Docker Compose, миграции Alembic, CI и релизные образы GHCR.
