# Changelog

## Unreleased

- PM: вопросы по данным без запуска исследования, отдельные режимы поручения и подготовки следующей итерации.
- Ограниченные расчёты CSV/TSV с сохранением источников, фильтров и результатов в чате.
- Память проекта с происхождением утверждений, применимостью и историей замены; снимки контекста и межитерационная передача.
- Отдельный накопительный бюджет общения PM, консервативное резервирование и проверки с имитацией модели без платных API-вызовов.

- Версии целей исследования, связанные итерации и сохранённая постановка каждого запуска.
- История целей и итераций в интерфейсе, подготовка итерации без вызовов модели.
- Аддитивная миграция старых Run с сохранением исходных снимков и checkpoints.
- Идемпотентные операции, защита от устаревших версий и проверки PostgreSQL без API модели.

## 0.1.0

- Пространство проектов с загрузкой данных, настройками исследования и чатом PM.
- Динамические команды AI-агентов и сессии LangGraph с PostgreSQL checkpoints.
- Раздельные сервисы HTTP API, worker и Python executor.
- Пауза, продолжение, финализация, остановка и восстановление исследований.
- Независимая проверка кандидатов, история запусков и скачивание артефактов.
- Настройки подключения модели, шифрование API-ключа и учёт расходов.
- React/TypeScript frontend с функциональной декомпозицией.
- Docker Compose, миграции Alembic, CI и релизные образы GHCR.
